## Português

Obrigado por querer ajudar. Aqui o padrão é simples: **clareza pra leigo** e **cuidado com dados**.

### Como ajudar (sem ser programador)

1. Use a ferramenta.
2. Abra um **issue** com o template de feedback.
3. Conte o que quebrou, o que ficou confuso no README, ou o que faltou.
4. Não cole chave de IA, senha, nem dado pessoal de clientes.

### Como ajudar com código

1. Abra um issue descrevendo o problema ou a ideia (evita trabalho duplicado).
2. Fork → branch com nome curto (`fix/…`, `docs/…`, `feat/…`).
3. Mudança pequena e focada. README e avisos de risco/LGPD atualizados se a mudança afetar uso ou privacidade.
4. Pull request apontando pro issue.
5. Sem surpresa: nada que envie dado pra terceiro sem opt-in; WhatsApp continua read-only e com rate limit, salvo decisão explícita documentada.

### Padrões que não negociamos

- Nome no formato `Donos …`.
- README em PT-BR claro (EN pode acompanhar).
- Instalação em um comando ou Docker.
- Dados locais; chave de IA do usuário.
- Licença, `CHANGELOG`, tags de versão.
- Avisos explícitos de ban-risk e LGPD em ferramentas de WhatsApp.

Dúvida? Abra um issue. É o caminho certo.

## English

Thanks for wanting to help. The bar here is simple: **clarity for laypeople** and **care with data**.

### How to help (without coding)

1. Use the tool.
2. Open an **issue** with the feedback template.
3. Say what broke, what was confusing in the README, or what was missing.
4. Don’t paste AI keys, passwords, or customers’ personal data.

### How to help with code

1. Open an issue describing the problem or idea (avoids duplicate work).
2. Fork → short-named branch (`fix/…`, `docs/…`, `feat/…`).
3. Small, focused change. Update README and risk/LGPD warnings if the change affects use or privacy.
4. Pull request linking the issue.
5. No surprises: nothing that sends data to a third party without opt-in; WhatsApp stays read-only and rate-limited unless an explicit, documented decision says otherwise.

### Non-negotiable standards

- Name in the `Donos …` line.
- Plain PT-BR README (EN may follow).
- Install in one command or Docker.
- Local data; user’s own AI key.
- License, `CHANGELOG`, version tags.
- Explicit ban-risk and LGPD warnings on WhatsApp tools.

Unsure? Open an issue. That’s the right path.
